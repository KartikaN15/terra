**Character rules** (for a cohesive mascot family):
- Faceless-friendly: dots for eyes, no mouth (dodges uncanny valley, keeps set cohesive)
- Rounded, egg/pear proportions   — no realistic anatomy
- Soft fabric in emerald, cream, or amber tones only
- Thumbprint-sized props are okay (cameras, clapboards, leaves, turbines)

**Negative prompts** (Midjourney `--no`, SDXL neg):
> *photorealistic, hyperrealistic skin, sharp teeth, mouths, realistic eyes, text, watermark, logo, neon colors, cyberpunk, grunge, harsh shadows, low poly, voxel*

## Practical tips

### Midjourney v6
- Use `--ar 1:1 --s 200 --style raw` to suppress over-rendering.
- Use `--cref <url>` with Prompt 11 (Terra mascot) to keep characters consistent across all other prompts.
- Fix seed with `--seed 12345` once you get a good base render.

### Flux (locally or via Replicate)
- Guidance scale ~3.5 (not 7+   — lower = less "overcooked")
- 30 steps is plenty for clay style
- Add `"clay render, plasticine, soft matte"` to the front of the prompt for stronger material adherence

### SDXL
- Use the `3d-render` LoRA or `clay-render` LoRA if you have one
- Sampler: DPM++ 2M Karras, 25 steps
- CFG 5–6

### Post-processing checklist
1. Remove background → `rembg` or Photoshop → save as transparent PNG.
2. Add a subtle drop shadow in CSS (`filter: drop-shadow(0 12px 24px rgba(16,185,129,0.15))`).
3. Export at 2× the display size for retina.
4. Drop into `frontend/src/assets/illustrations/` with kebab-case names:
   ```
   hero-planet.png
   empty-sprout.png
   mascot-terra.png
   upload-courier.png
   scope-worlds.png
   …
   ```
5. Import in React: `import heroPlanet from "../assets/illustrations/hero-planet.png";`

### Consistency checks before committing
- [ ] All illustrations share the same lighting direction (upper-left default)
- [ ] Emerald hue is consistent (#10B981 ± 10)
- [ ] No illustration uses a color outside the palette (emerald, cream, amber, slate, white)
- [ ] Characters share the same faceless dot-eye style
- [ ] All props feel the same scale (no giant photorealistic items next to tiny clay ones)

## Generation workflow suggestion

1. **Start with Prompt 11** (Terra mascot)   — render 8 variants, pick one, fix the seed.
2. Use that seed + `--cref` as your character reference across Prompts 4, 5, 10.
3. Generate Prompts 1, 2, 7 next (environment scenes) to set the world.
4. Generate Prompts 3, 6, 8, 9, 12 last (abstract/object compositions)   — these are the most stylistically forgiving.
5. Iterate: if anything feels off-palette, re-roll with the palette reinforced in the suffix.
