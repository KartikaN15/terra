Development — Embed sustainability at greenlight
Set science-based carbon budget: Use genre + budget + shoot-day benchmarks (e.g., 1-hr drama ≈ 77 tCO₂e/episode) to set a per-episode or per-film emissions cap aligned with SBTi trajectory.
Hire green production manager / consultant: Bring in a sustainability lead before locations are locked so travel and logistics can be designed low-carbon from the start.
Draft footprint (preliminary): Use BAFTA Albert or PEAR to model expected emissions by category: transport, energy, materials, accommodation, post/VFX.
Green vendor shortlist: Query the Green Production Guide sustainable vendor database and regional green film commissions for local clean mobile power, EV rental, and zero-waste catering options.
Location climate scan: Prioritize locations with grid-tie access (avoids diesel), renewable energy availability, and proximity to crew base to reduce hotel nights and transit.
Pre-Production — Design out emissions before day 1
Carbon Action Plan (CAP): Complete the Albert CAP or PEACH+ checklist. Define targets, department owners, and reporting cadence. Integrate into production calendar.
Clean mobile power procurement: Lock battery trailers, solar rigs, or hydrogen units instead of diesel generators. Confirm load profiles with the power team (target: 140–220 kW three-phase for 14 hrs).
Transportation plan: Prioritize EV/PHEV fleet; book cast/crew on direct flights; consolidate travel days; set ground-transport policy (shuttles > individual cars).
Set & costume strategy: Source reclaimed / second-hand materials; design for disassembly and donation; avoid landfill-bound single-use builds.
Catering RFP with sustainability clauses: Require local/seasonal menus, plant-forward options, bulk service (no individual packaging), and composting infrastructure.
Waste infrastructure: Order colour-coded bins, engage a local hauler for diversion tracking, and brief all HoDs on set-wide sorting rules.
Green Rider draft: For above-the-line talent, agree on sustainable trailer power, reusable bottles, local accommodation, and low-emission transport clauses.
Production — Execute, measure, and adapt on set
Daily fuel & power logging: Record generator runtime vs. battery/solar runtime; log diesel, renewable diesel, and HVO consumption by unit. Aim for >20% fuel reduction; top performers hit >50%.
Real-time carbon tracker: Update the Albert calculator or Footprint dashboard weekly. Flag overspends against the carbon budget early so departments can course-correct.
Crew engagement & nudges: Daily call-sheet sustainability tips; water refill stations (eliminate single-use plastic); digital distro (minimise printing).
Waste diversion tracking: Weigh landfill, recycling, compost, and donation streams. Target >50% diversion. Donate viable set pieces, wardrobe, and props to local schools / theatre groups / next production.
On-set EV charging: Use temporary DC fast chargers or mobile charging units for electric box trucks and cast/crew shuttles. Track kWh drawn vs. gallons avoided.
Material reuse loops: Coordinate with the art department to reuse lumber, flats, and hardware across episodes or productions. Use the PLUM worksheet to track sustainable plywood.
Post-Production — Render efficiently and account accurately
Green facility preference: Use post houses running on 100% renewable electricity. For VFX/render farms, prioritise cloud regions with high renewable penetration (AWS already 99% renewable for Netflix workloads).
Render scheduling: Batch overnight jobs to exploit off-peak grid carbon intensity. Optimise deliverables to avoid unnecessary re-renders.
Final carbon footprint: Reconcile all invoices, fuel logs, travel manifests, and waste receipts. Classify every line item into Scope 1, 2, or 3 with the correct emission factor.
Extrapolation & confidence scoring: For missing data, apply the tiered extrapolation engine (statistical, benchmark, or ML) and compute the confidence-adjusted score.
Production sustainability report: Compile a board-ready PDF: total tCO₂e, per-episode intensity, scope breakdown, confidence level, reduction actions taken, and residual offset plan.
Distribution — Minimise streaming & CDN footprint
Open Connect efficiency: Netflix localises content to ISP edge nodes (6,000+ locations). Encoding optimisations (per-title, per-device) reduce bitrate without quality loss, cutting data-centre and network energy.
Codec & compression roadmap: Adopt next-gen codecs (AV1, etc.) as they mature to further shrink file sizes and bandwidth per view.
Member device guidance: Surface actionable tips in-app or on help pages: use Wi-Fi vs. cellular, lower brightness, and avoid autoplay when not viewing.
Cloud carbon accounting: Use AWS customer carbon footprint tooling to attribute data-centre and storage emissions to the title. Report under Scope 3 upstream.
Reporting — Certify, benchmark, and improve
Albert certification submission: Upload final footprint + Carbon Action Plan for independent audit. Successful completion grants use of the albert logo on end boards.
EMA Green Seal / PEACH+: For US productions, complete the Production Environmental Actions Checklist and secure third-party verification where required.
SBTi progress reporting: Map production-level reductions to corporate near-term targets (Netflix: 46% Scope 1+2 reduction vs. 2019 baseline by 2030). Report via CDP or annual ESG.
Peer benchmarking: Compare per-episode or per-production-day intensity against SPA industry averages and prior Netflix seasons. Identify outliers and best practices.
Improvement roadmap: Feed lessons learned into the next greenlight. Update vendor scorecards, emission factors, and the ML extrapolation model with new production data.
End-to-end principle: The cheapest and most effective carbon reduction happens at the design stage (pre-production). Every diesel generator avoided through grid-tie planning, every flight consolidated, and every set piece designed for reuse delivers compounding savings that cannot be matched by offsetting alone.
Decarbonisation strategy

Optimise · Electrify · Decarbonise

Netflix's operational decarbonisation framework: Optimise energy use first, Electrify what you can, then Decarbonise the remainder. Applied across productions, offices, and streaming infrastructure.

1Optimise
  • Energy efficiency audits for offices, studios, and stages
  • Right-size vehicles and mobile power to actual load (avoid oversized generators)
  • Prefer efficient equipment: LED lighting, efficient HVAC, variable-speed drives
  • Consolidate travel and logistics to reduce total trip volume
  • Digital distribution; minimise printed sides, call sheets, and production docs
  • Reusable set elements and wardrobe instead of single-use builds
Target: reduce baseline demand before switching fuels
2Electrify
  • Replace diesel generators with battery trailers, solar rigs, and hydrogen-battery hybrids
  • Swap ICE vehicles for EVs, PHEVs, and hybrids on set and in corporate fleet
  • Install DC fast chargers at studio hubs; deploy mobile chargers to remote locations
  • Electric heat pumps and geothermal for owned studios (e.g., Albuquerque campus)
  • Grid tie-ins at soundstages to eliminate basecamp generator runtime
  • Pilot medium-duty EV box trucks (5-ton, shorty 40, flatbed) in Vancouver, LA, NM, UK
Target: shift energy demand to electricity (easier to decarbonise)
3Decarbonise
  • 100% renewable electricity via green tariffs, PPAs, and RECs for all facilities
  • On-site solar + battery storage (e.g., 5 MW solar / 3 MW battery at Albuquerque)
  • Renewable diesel and renewable natural gas where electrification isn't yet feasible
  • Sustainable aviation fuel (SAF) certificates via Sustainable Aviation Buyers Alliance
  • High-quality carbon insets and removals for truly unavoidable residual emissions
  • Natural climate solutions (reforestation, restoration) as last resort after reductions
Target: eliminate carbon intensity of remaining fuel and energy use

Data quality

Tiered confidence model

Every emission source is assigned a data quality tier. Where data is missing (Tier 3), the extrapolation engine fills the gap and applies a confidence penalty to the final score. Critical because ~50–70% of emissions sit in Scope 3, where supplier data is often fragmented.

Tier 1 · Directly measured
90–100% confidence
Meter readings, fuel invoices, energy bills, on-site IoT sensors, weighbridge tickets. No estimation needed. Full weighting in score calculation.
Tier 2 · Supplier provided
60–80% confidence
Vendor EPDs, airline emission factors, hotel sustainability reports, hauler diversion certificates. Confidence depends on third-party verification and methodology transparency.
Tier 3 · Extrapolated
30–70% confidence
No direct data available. The extrapolation engine applies one of three methods and assigns a confidence factor that narrows the final score range.
Extrapolation methods (Tier 3)
Statistical extrapolation
~50–65%
Mean/median from comparable productions matched by genre, budget tier, shoot days, location climate, and crew count. Best for catering, materials, and crew-count-based estimates.
Benchmark reference
~40–55%
Per-episode or per-production-day emission factors from BAFTA Albert, the Green Production Guide (PEAR), or GHG Protocol industry averages for unknown supplier categories.
ML / regression model
~60–70%
Trained on historical Netflix production data. Features: budget, genre, shoot days, cast size, location, VFX load. Gradient boosting handles non-linear emission patterns well.
Methodology

Score formula

Sraw  = Σ (wscope × emission_intensity)
C      = Σ (wscope × tier_confidence)
Sfinal = Sraw × C  ± ΔCI
Default scope weights: Scope 1 = 15% · Scope 2 = 25% · Scope 3 = 60%

ML core

ML engine — three model families that predict, infer, and learn

A single model can't cover a production's emission landscape. We compose three families: gradient-boosted trees for structured imputation, an LLM agent for unstructured extraction, and a graph neural network for supply-chain propagation. Each has its own training cadence, confidence model, and human-in-the-loop fallback.

Family 1 · Tabular
Gradient boosting (XGBoost / LightGBM)
Per-category regressors that predict missing Tier 3 emissions from production metadata + partial activity data. The workhorse — handles ~70% of all imputation.
  • One model per emission category (catering, transport, materials, waste)
  • 40–80 features per model, Optuna-tuned hyperparameters
  • SHAP attribution per prediction → full explainability
  • Bootstrap ensemble for prediction intervals
  • Reference: HBS Scope 3 prediction R² ~ 0.77
Trained nightly · LightGBM · Optuna · MLflow registry
Family 2 · Unstructured
RAG + LLM extraction agent
Reads vendor PDFs, sustainability reports, and emission-factor databases. Returns structured JSON with citations + confidence. Closes the gap on Scope 3 supplier data.
  • OCR (Textract / Mistral OCR) → chunk → embed (text-embedding-3)
  • Retrieval over EPDs, ESG reports, EPA / DEFRA / IPCC factor DBs
  • Claude Opus 4.7 for high-stakes; Haiku 4.5 for high-volume
  • Output schema-validated (Pydantic) and grounded with citations
  • Low-confidence extractions routed to human review queue
Streaming · Anthropic + Pinecone · LangGraph orchestration
Family 3 · Graph
Graph Neural Network (supply chain)
Models suppliers as nodes, procurement edges as relationships. Imputes missing Scope 3 supplier emissions via message passing — handles the cold-start problem for new vendors.
  • GraphSAGE / GAT trained on cross-production vendor graph
  • Node features: industry NAICS, size band, country, prior disclosures
  • Edge features: spend, category, frequency
  • Bootstrapped from HBS GHG factor dataset + Netflix's vendor master
  • Refreshed quarterly as vendor relationships evolve
PyTorch Geometric · DGL · weekly retrain
Ensemble & routing: A meta-controller routes each line item to the right model based on data availability — direct measurement first, then LLM extraction if vendor docs exist, then gradient boosting on metadata, then GNN supply-chain inference as last resort. Routing decisions are logged so the data team can see exactly which model produced every number.
