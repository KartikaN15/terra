## Generation Tips

| Tip | Why |
|-----|-----|
| Always request **transparent PNG** or pure white background | Easy to composite onto Terra's pale-green card backgrounds |
| Fix seed + aspect ratio per slide placement | Consistent style across the deck |
| Use `--style raw` (Midjourney) or low guidance scale (Flux ~3.5) | Prevents over-realistic materials; keeps clay look |
| Keep characters **faceless** (dot eyes, no mouths) | Avoids uncanny valley; keeps set cohesive |
| Batch generate all images with the same seed range | Visual consistency across all 11 slides |
| Save outputs as `terra_slide_01.png` through `terra_slide_11.png` | Easy mapping to slides |
