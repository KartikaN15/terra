# Slide 10 — The Long Run: Where Terra Goes Next

## Slide Title
Building the Universal Carbon Kernel — One Domain at a Time

## The 24-Month Vision
Terra starts as a film production companion. It evolves into the **industry-agnostic carbon intelligence layer** that any domain can plug into.

## Phase Roadmap

### Phase 0 — Foundation (Now)
- ✅ Universal 4-entity schema (Project → Event → Factor → Calculation)
- ✅ Domain-agnostic YAML configuration system
- ✅ Core calculation engine with DEFRA/EPA factor registry
- ✅ Tiered confidence scoring (Tier 1/2/3)
- ✅ Greenlight predictor (XGBoost) + Anomaly detector

### Phase 1 — Film & TV Vertical (Months 1-6)
- Full production lifecycle tracking (Development → Wrapped)
- BAFTA albert / PEAR-compatible export
- Document AI: invoice OCR + LLM extraction + human review queue
- OED Playbook with costed recommendations
- Real-time dashboard with scope/category/phase breakdowns

### Phase 2 — Multi-Domain Expansion (Months 6-12)
| Domain | Config Key | Unique Twist |
|--------|-----------|--------------|
| **Construction** | `construction` | Concrete volume, steel tonnage, LEED levels |
| **Logistics** | `logistics` | Route optimisation, refrigerated chains, fleet EV transition |
| **Corporate** | `corporate` | Office energy, business travel, cloud compute, supply chain |
| **Events** | `events` | Venue energy, attendee travel, food & beverage, waste |

### Phase 3 — Intelligence Layer (Months 12-18)
- **Graph Neural Network supply-chain propagation** — Scope 3 emissions that trace upstream through vendors
- **Real-time IoT streaming** — Smart meter + sensor ingestion (no more manual logging)
- **Multi-tenant SaaS** — One Terra instance serving multiple organisations with RBAC
- **Custom LLM fine-tuning** — Domain-specific language models trained on Terra's corpus

### Phase 4 — Network Effects (Months 18-24)
- **Peer benchmarking** — "Your production is 23% more carbon-efficient than peers in your budget band"
- **Vendor scorecards** — Green-certified suppliers ranked by real emission performance
- **Carbon marketplace integration** — Offset purchases, renewable energy credits, insets
- **Regulatory auto-compliance** — CDP, ISSB IFRS S2, SEC climate disclosures auto-populated

## Speaker Notes
This is not a film tool that grew bigger than intended. Terra was always designed as a universal kernel. The film vertical is our proof of concept because production carbon data is rich, benchmarked, and urgently needed. But the same four-entity pattern works for a construction site pouring concrete, a logistics fleet routing trucks, or a corporate office buying cloud compute. The long run isn't about adding features. It's about adding *worlds*. And every new domain makes every other domain smarter because the ML engine learns across boundaries.
